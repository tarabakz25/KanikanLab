# Astroでのマークダウン活用法

Astroでは**マークダウン**を使って簡単にブログ記事を書くことができます。この記事では、マークダウンの基本的な使い方と、Astroでの特別な機能について解説します。

## マークダウンの基本

マークダウンは簡単な記法で文書を書くことができるフォーマットです。以下に基本的な記法を示します：

### 見出し

```
# 見出し1
## 見出し2
### 見出し3
```

### リスト

```
- 箇条書き1
- 箇条書き2
  - ネストされた箇条書き

1. 番号付きリスト1
2. 番号付きリスト2
```

### 強調

```
*イタリック*
**太字**
***太字かつイタリック***
```

### リンク

```
[リンクテキスト](https://example.com)
```

### 画像

```
![代替テキスト](/path/to/image.jpg)
```

## Astroでの特別な機能

Astroではマークダウンに加えて、フロントマターと呼ばれるYAML形式のメタデータを記事の先頭に追加することができます。

```yaml
---
title: '記事のタイトル'
description: '記事の説明'
pubDate: '2023-01-01'
updatedDate: '2023-01-02'
heroImage: '/path/to/image.jpg'
---
```

これらのメタデータは、記事の表示やSEOに活用されます。

### コードブロック

Astroではシンタックスハイライトが標準で対応しています：

```typescript
// TypeScriptのコード例
interface User {
  id: number;
  name: string;
  email: string;
}

function greetUser(user: User) {
  console.log(`こんにちは、${user.name}さん！`);
}
```

## まとめ

マークダウンを使うことで、HTMLを直接書くことなく、簡単に構造化された文書を作成することができます。Astroのコンテンツコレクション機能と組み合わせることで、効率的にブログを管理することができます。

ぜひマークダウンを活用して、素晴らしいブログ記事を書いてみてください！
