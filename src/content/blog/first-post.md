# Kanikan Labへようこそ

これは**Astro**を使って作成された最初のブログ投稿です。Astroは高速なウェブサイトを構築するための最新のウェブフレームワークです。

## Astroの特徴

Astroには以下のような特徴があります：

1. **高速パフォーマンス** - Astroはゼロ JavaScript をデフォルトで提供し、必要な場合にのみJavaScriptを追加します。
2. **コンテンツ中心** - ブログやドキュメントサイトなどのコンテンツ中心のウェブサイトに最適です。
3. **UIに依存しない** - React、Vue、Svelte、Solidなど、お好みのUIフレームワークを使用できます。
4. **コンテンツコレクション** - Markdownファイルを簡単に管理し、型安全に扱うことができます。

## コードサンプル

以下は簡単なJavaScriptのコードサンプルです：

```javascript
// シンプルな挨拶関数
function greet(name) {
  return `こんにちは、${name}さん！`;
}

console.log(greet('Kanikan'));
```
